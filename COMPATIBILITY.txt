Local compatibility modifications, 2026-10-24:
- Clear the voxel table with a two-dimensional compute dispatch, within the
  OpenGL portable per-dimension group-count limits and matching VOXEL_ARRAY_SIZE.
- Clear exactly the 1024 texture hash keys instead of writing 4096 array slots.
- Apply the initialization fixes in the overworld, Nether and End.
- Replace rectangular texture-matrix conversion with equivalent full mat4
  multiplication followed by .xy, for visible geometry, POM bounds, sky geometry
  and voxel capture. This addresses the previously observed zero-V UV issue.
- Enable the existing specular-map option by default for the active LabPBR pack.
  Preserve its material values in the main view and atlas-backed ray hits instead
  of overwriting them with integrated materials. Non-atlas ray hits retain the
  original integrated-material fallback because no specular sidecar is captured.
- Set irradiance-cache smoothing numerically in profiles rather than using
  boolean profile syntax for the three-valued option.
- Complete the advertised 16384-entry irradiance-cache setting: allocate 524288
  bytes and dispatch 256 groups of 64 invocations for initialization and updates.
- Correct the DIFFUSE_SAMPLES macro in the two-sample blue-noise resource branch,
  selecting HeitzData_2spp.bin when the diffuse sample count is 2.
- Add Performance, Balanced, High and Ultra profiles with explicit assignments
  for the same quality controls. Defaults match Balanced and enable normal
  mapping and POM. Keep texture resolution, POM depth, capture settings and
  memory-pool capacities independently adjustable.

Default sample counts, distances and capacities are retained; the new quality
profiles offer different sampling budgets. Disabling specular mapping restores
the integrated-material mode when IPBR is enabled.
The latest preset changes have only received static source, include, diff and
archive-manifest inspection. Compilation, appearance and performance of this
revision have not been verified in Minecraft.
